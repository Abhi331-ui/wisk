# Cinematic Comic Storytelling AI Toolkit

Files:
- `SKILL.md`: Claude skill instructions for the complete storytelling and production workflow.
- `REFERENCE_ANALYSIS_PROMPT.md`: Deep prompt for analyzing the supplied reference video.
- `ANTIGRAVITY_MASTER_PROMPT.md`: Workspace/production-system prompt for Antigravity.
- `CLAUDE_MASTER_PROMPT.md`: Master prompt for Claude as story director and camera choreographer.

Important:
The prompts require the AI to inspect the actual video. They do not assume that a contact sheet proves camera motion. The AI must distinguish observed evidence from inference and report limitations.
